=== 2026-08-19T17:15:48.507Z ===
Now here is the premiums calculater service File: /backend/services/premium_calculator.py

Function: calculate_premium(age, gender, coverage_amount, 
          rate_class_name, product_type="L")
  
  Validation:
    - age must be 50-85, else raise ValueError("Age must be 50-85")
    - coverage must be within min/max from coverage_options table
    - coverage must be divisible by step (1000)
    - rate_class_name must exist in rate_classes table
  
  Logic:
    1. Look up rate_per_1000 from rate_base for (age, gender, product_type)
    2. Look up multiplier from rate_classes for rate_class_name
    3. monthly = rate_per_1000 × (coverage_amount ÷ 1000) × multiplier
    4. annual = monthly × 12
    5. Return rounded to 2 decimal places
  
  Return: {
    "monthly_premium": 77.38,
    "annual_premium": 928.56
  }


Function: get_all_quotes(age, gender, coverage_amount, 
          tobacco_use, product_type="L")
  
  Validation:
    - Same age and coverage validations as above
  
  Logic:
    1. Look up base rate for (age, gender, product_type)
    2. Get ALL rate_classes from database
    3. For each rate class:
       - If tobacco_use=false AND rate_class.requires_tobacco=true
         → mark as "N/A" with reason "Tobacco rate class - not applicable"
       - If tobacco_use=true AND rate_class.requires_tobacco=false
         → mark as "N/A" with reason "Non-tobacco rate class - not applicable"
       - Otherwise → calculate premium
    4. Return list sorted by monthly_premium ascending
  
  Return: [
    {
      "rate_class": "Level Preferred", 
      "monthly": 77.38, 
      "annual": 928.56, 
      "eligible": true
    },
    {
      "rate_class": "Level Non-Tobacco", 
      "monthly": 91.80, 
      "annual": 1101.60, 
      "eligible": true
    },
    {
      "rate_class": "Modified Non-Tobacco", 
      "monthly": "N/A", 
      "annual": "N/A", 
      "eligible": false, 
      "reason": "Not available for this applicant"
    }
  ]


Function: recalculate_for_coverage(age, gender, new_coverage, 
          tobacco_use, product_type="L")
  
  Purpose: When user moves the coverage slider, recalculate 
  ALL rate classes instantly for the new amount.
  
  Logic:
    1. Validate new_coverage is within allowed range and step
    2. Call get_all_quotes with new_coverage
    3. Return updated premiums for all rate classes
  
  This is the SAME as get_all_quotes but named explicitly 
  for the coverage change use case. The frontend calls this 
  every time the user changes the coverage amount.


Function: get_coverage_options(product_type="L")
  
  Purpose: Tell the frontend what coverage range to show
  
  Return: {
    "min": 5000,
    "max": 50000,
    "step": 1000,
    "default": 35000
  }
